> 🎯 **学完这一阶段你能做到**:写一个拦截器,让没令牌的请求被"检票员"拦下;并把它注册进 WebConfig。
> 📌 前置:已会阶段一的 JwtUtils(generateToken/parseToken)、登录接口发令牌。
> ✨ 风格:emoji + 生活类比 + 英文拆词。

---

## 🎬 一、为什么需要拦截器(先懂动机)

阶段一做的:登录成功 → 发一张 JWT(电影票)给前端。

**但现在的问题**:
```
发了票,但【没人查票】!
→ 即使不带 JWT,也能访问 /emps、/depts
→ 就像电影院门口没人检票,没票也能进
```

**拦截器 = 门口的检票员**:每个请求进来,先"查票"(验 JWT),有票放行,没票/假票拦下。

---

## 🕐 二、拦截器在什么时候执行(执行时机)

```
浏览器请求 /emps
    ↓
   ◆ 拦截器 preHandle  ←【在这里查票!】
    ↓  (有票 → return true 放行; 没票 → return false 拦下)
Controller 处理请求
    ↓
   ◆ 拦截器 afterCompletion(事后,可选)
    ↓
返回给前端
```

**关键**:拦截器在 **Controller 之前**先跑一遍,像门卫先拦人、才让你进办公室。

---

## 🧩 三、核心接口和注解(拆词)

| 词 | 英文本意 | 代码里意思 |
|----|---------|-----------|
| **Interceptor** | inter(在..之间)+Ceptor(拦截者) | 拦截器,在请求处理前后"插一脚" |
| **HandlerInterceptor** | Handler(处理器)+Interceptor | Spring 提供的"拦截器接口" |
| **preHandle** | pre(前)+Handle(处理) | 进 Controller **前**执行的方法 |
| **postHandle** | post(后)+Handle | 进 Controller **后**执行(可选) |
| **afterCompletion** | Completion(完成之后) | 请求**全部完成**后执行(可选) |

**你只需要实现 `preHandle`**(最核心的查票逻辑),返回 `boolean`,控制放不放行。

## 🛠️ 四、拦截器代码(完整 + 注释)

新建 `com/shyc/interceptor/LoginInterceptor.java`:

```java
package com.shyc.interceptor;

import com.shyc.utils.JwtUtils;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

/**
 * 登录拦截器 = 门口的"检票员"
 * 每个请求进 Controller 前,先查 JWT(电影票),没票/假票就拦下。
 *
 * HandlerInterceptor(处理器拦截器) = Spring 提供的拦截器接口
 * preHandle(pre=前+handle=处理)   = 进 Controller 前执行
 */
@Component
public class LoginInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        // ① 从请求头拿 token(前端把令牌放在 Headers 里, key 叫 token)
        //    getHeader  = get(拿)+Header(头) | 从 HTTP 请求头取某键的值
        String token = request.getHeader("token");

        // ② 没带 token → 拦下,返回"未登录"
        if (token == null || token.isEmpty()) {
            response.setStatus(401);   // 401 = Unauthorized(未授权)
            response.getWriter().write("{\"code\":0,\"message\":\"NOT_LOGIN\"}");
            return false;              // return false = 拦下,不进 Controller
        }

        // ③ 带了 token → 解析验证(合法才放行)
        try {
            JwtUtils.parseToken(token);   // 能解析=合法; 抛异常=非法/过期
            return true;                  // return true = 放行
        } catch (Exception e) {
            // 伪造/过期 → 拦下
            response.setStatus(401);
            response.getWriter().write("{\"code\":0,\"message\":\"NOT_LOGIN\"}");
            return false;
        }
    }
}
```

### 关键三处(背下来)

1. **`request.getHeader("token")`** = 从请求头拿令牌。
2. **`return false`** = 拦下(不进 Controller);**`return true`** = 放行。
3. **`JwtUtils.parseToken(token)`** = 验票;try-catch 里能解析就合法,异常就非法。

### 类比 🎫

```
前端请求 → 出示'd 票(token)
  门卫(拦截器)看票:
    没票/假票 → "401 没票!" 拦下(return false)
    真票       → "请进"(return true) → 放行到 Controller
```

## 📋 五、注册拦截器(第 2 步,WebConfig 里配)

拦截器写了还**没用**——得像"门卫排班表"一样,告诉 Spring"哪个路径要拦、哪些不拦"。

在你的 `WebConfig` 加:

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    // loginInterceptor | 需要 @Autowired 注入(拦截器是 @Component Bean)
    @Autowired
    private LoginInterceptor loginInterceptor;

    // addInterceptors = add(添加)+Interceptor(拦截器) | 注册拦截器的方法
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(loginInterceptor)     // 登记这个拦截器
                .addPathPatterns("/**")                // 拦哪些路径:所有(/** = 全部)
                .excludePathPatterns("/login",         // 排除:登录接口(不用带票)
                                     "/images/**");    // 排除:图片(不用登录)
    }
}
```

### 拆词(双语)

| 词 | 意思 |
|----|------|
| **addInterceptors** | add(添加)+Interceptors(拦截器) = 注册拦截器的方法 |
| **InterceptorRegistry** | Interceptor(拦截器)+Registry(登记表/注册表) = 拦截器的"登记表" |
| **addInterceptor** | 往登记表加一个拦截器 |
| **addPathPatterns** | add(加)+Path(路径)+Patterns(模式) = 要拦截哪些路径 |
| **excludePathPatterns** | exclude(排除)+PathPatterns = 哪些路径不拦截 |
| **`/**`** | 通配符 = 所有路径 |
| **`/login`** | 登录接口,不用带票(还没票呢) |

### 为什么排除 /login 和 /images

- **`/login`**:登录时前端还没令牌,不能拦(拦了没法登录)。必须放行。
- **`/images/**`**:上传的图片(头像),浏览器直接访问,不需要令牌。放行。

**其他**(/emps、/depts、/upload)都要登录 → 拦截。

## ⚠️ 六、必踩的坑(记住)

| 坑 | 说明 | 对策 |
|----|------|------|
| 忘了排除 /login | 登录接口被拦,永远登录不上 | `excludePathPatterns("/login",...)` |
| 拦截器没配 @Component | Spring 不认,注入报错 | 加 `@Component` |
| addPathPatterns 写错 | 拦多了/拦少了 | `/**` 拦全部,`/login` 排除 |
| 忘了 import JwtUtils/HandlerInterceptor | 编译报错 | IDEA Alt+Enter 补 |
| exclude 写成 include | 反了 | exclude=排除,add=拦 |
