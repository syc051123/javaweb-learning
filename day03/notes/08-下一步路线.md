## 二、下一步第一步：员工新增(POST /emps)

**难度**：⭐⭐ 和部门新增几乎一样,属于"复制套路"。

**知识点(全是旧的,你都会)**：
- `@PostMapping` + `@RequestBody`(接收 JSON)→ 部门新增已经用过
- Service 补 `createTime`/`updateTime` → 部门新增已经用过
- `@Insert` SQL → 部门新增已经用过

**唯一新东西**：`emp` 表字段比 `dept` 多(10 个字段),SQL 写长一点而已。

**思路**(不用我教,你自己照部门套路写)：
```
Controller:  @PostMapping 接收 Emp 对象 → 调 service
Service:     补两个时间 → 调 mapper
Mapper:      @Insert("insert into emp(...) values(...)")
```

## 三、下一步第二步：员工删除 + 修改(带教课)

**难度**：⭐⭐⭐ 删除和修改是"最后两节带教课",有**新知识点**。

### 删除(DELETE /emps?id=1)

**新东西:批量删除**
```
DELETE /emps?ids=1,2,3     ← 一次删多个
```
- Controller 参数用 `List<Integer> ids`(Spring 自动把 `1,2,3` 拆成 List)
- Mapper 用**动态 SQL 的 `<foreach>`**(遍历 id 列表,生成 `IN (1,2,3)`)
- 这是你第一次用 `<foreach>`,也是唯一的新知识点

### 修改(PUT /emps)

**新东西:回显查询(前面部门学过) + 数据回填**
- 点"编辑"按钮 → 前端先 `GET /emps/{id}` 拿到这条数据填进表单(回显,部门学过)
- 改完点保存 → `PUT /emps` 提交整个对象
- 和部门修改**一模一样**,`@PutMapping + @RequestBody`,无新知识点

**注意坑**:修改员工的 `image`(头像)字段——如果用户没换头像,前端会传空字符串,你得决定是更新为空还是保留原值(进阶点,先不管)。

## 四、下一步第三步：文件上传(独立知识点)

**难度**：⭐⭐⭐ 这是员工管理里**唯一全新的技术**,跟增删改无关。

**干什么用的**：员工头像(图片)要上传到服务器。

**知识点**：
| 概念 | 说明 | 类比 |
|------|------|------|
| `MultipartFile` | Spring 接收文件的对象 | 快递员递给你一个"文件包裹" |
| 存储位置 | 保存到本地磁盘 + 返回访问 URL | 放仓库,给你取货码 |
| 配置文件 | 上传大小限制、存储目录 | 仓库规则 |

**坑(必踩)**：
- Apifox 里选 `form-data` 类型,不是 JSON(文件不能塞 JSON)
- 文件名不能直接用用户传的(有安全风险),要用 UUID 重命名
- 上传目录要配成绝对路径,别用相对路径(重启会丢)

## 五、员工管理做完后：登录认证(JWT)

**难度**：⭐⭐⭐⭐ 项目里最"绕"的一块,但也是面试最常问的。

**解决的问题**：现在任何接口都能随便调,没有"你是谁"的概念。登录后发给你一张**令牌(JWT)**,以后每次请求带上它,服务器就知道"这是已登录用户"。

**新知识点**：
| 概念 | 说明 |
|------|------|
| JWT | 一串加密的字符串 = 令牌(类似电影票) |
| 拦截器(Interceptor) | 在请求进 Controller 前"查票",没票就拦下 |
| 登录接口 | POST /login,校验用户名密码,发令牌 |

**一句话流程**：
```
登录成功 → 服务器发 JWT 令牌 → 前端存起来
以后每个请求都带上令牌 → 拦截器验票 → 有效才放行
```

## 六、最后：AOP 日志(进阶)

**难度**：⭐⭐⭐⭐ 用"切面"自动记录操作日志,不用每个方法手动写 log.info。

**解决的问题**：现在每个 Controller 方法都要手动 `log.info(...)`,100 个方法写 100 遍。AOP = **写一次,自动给所有方法加日志**。

**新知识点**：
| 概念 | 说明 |
|------|------|
| AOP | 面向切面编程,在不改原方法的情况下"插一脚" |
| @Aspect | 标记切面类 |
| @Around | 环绕通知:方法执行前记录开始、执行后记录结束 |

**现状**：你已经在用 AOP 了(Spring 事务、PageHelper 都是 AOP 实现的),只是没意识到。
