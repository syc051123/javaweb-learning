## 二、后续课程路线图（40 集预告的内容）

从 41 集开始，你将进入 **Web 后端开发核心模块**，这是整个 JavaWeb 教程最长的章节（41~152 集）。

**按顺序：**

| 阶段 | 集数 | 学什么 |
|------|------|--------|
| **SpringBootWeb 入门** | 41~42 | 第一个 SpringBoot 程序、自动配置原理 |
| **HTTP 协议** | 43~45 | 请求响应格式、状态码 |
| **SpringBootWeb 案例** | 46~48 | 综合小案例实战 |
| **MySQL 数据库** | 49~73 | 数据库设计、SQL、JDBC |
| **MyBatis** | 74~92 | ORM 框架、增删改查 |
| **登录认证 & 拦截器** | 93~110 | Session、JWT、Filter、Interceptor |
| **AOP** | 111~120 | 面向切面编程 |
| **SpringBoot 原理** | 121~132 | IOC/DI、自动配置源码分析 |
| **Tlias 项目实战** | 133~152 | 综合项目开发 |

**再往后（153~200 集）：**
- Vue 工程化
- Tlias 项目前端 + 后端完整实现
- Linux + Docker 部署
