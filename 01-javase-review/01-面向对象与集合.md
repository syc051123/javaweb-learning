# 01 - JavaSE 核心巩固

## 面向对象三大特性

| 特性 | 核心要点 | 一句话理解 |
|------|---------|-----------|
| 封装 | private 私有属性 + getter/setter | 不想让别人碰的就藏起来 |
| 继承 | extends，子类复用父类 | 儿子能继承老子的东西 |
| 多态 | 父类引用指向子类对象 | 同一个方法，不同表现 |

```java
// 封装示例
public class Student {
    private String name;  // 私有化，外部不能直接访问
    private int age;      // 私有化

    // 通过公共方法访问私有属性
    public String getName() {
        return name;
    }
    public void setName(String name) {
        this.name = name;  // this 表示当前对象的name
    }
}
```

## 接口 vs 抽象类

```java
// 接口：定义"能做什么"
public interface Flyable {
    void fly();
}

// 抽象类：定义"是什么"
public abstract class Animal {
    public abstract void makeSound();  // 子类必须实现
    public void sleep() {              // 子类可以直接用
        System.out.println("睡觉中...");
    }
}
```

## 集合框架

```java
List<String> list = new ArrayList<>();
list.add("Java");
list.add("MySQL");

Map<String, Integer> map = new HashMap<>();
map.put("age", 18);
System.out.println(map.get("age"));  // 输出 18
```

## 常见面试题

> ArrayList vs LinkedList？
> ArrayList 底层数组，查询快增删慢。LinkedList 底层链表，增删快查询慢。

> == 和 equals() 区别？
> == 比较内存地址，equals() String 类比较内容。

> final 关键字？
> 修饰变量→常量，修饰方法→不能重写，修饰类→不能继承。
