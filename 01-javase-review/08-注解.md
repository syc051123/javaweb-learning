# 05 - 注解（⭐⭐ Spring 开发天天见）

## 一、什么是注解？

```java
// 注解 = 给代码贴标签
// @Override：告诉编译器"这是重写父类的方法"
// @Deprecated：告诉别人"这个方法过时了"
// @SuppressWarnings：告诉编译器"别报这个警告"

// 框架里的注解（后面会学到）：
// @SpringBootApplication：标记这是一个 SpringBoot 项目
// @GetMapping("/user")：标记这个方法处理 GET 请求
// @Autowired：自动注入对象
```

## 二、JDK 内置注解

```java
// @Override：检查方法是否正确地重写了父类方法
@Override
public String toString() {
    return "这是重写的 toString";
}

// @Deprecated：标记过时的方法，调用时会有删除线
@Deprecated
public void oldMethod() {
    System.out.println("这个方法过时了，别用了");
}

// @SuppressWarnings：压制警告
@SuppressWarnings("unchecked")  // 不检查类型转换警告
public void myMethod() {
    List list = new ArrayList();  // 没写泛型，但不报警告
}
```

## 三、元注解（注解的注解）

```java
// @Target：这个注解可以用在哪里
@Target(ElementType.METHOD)     // 只能用在方法上
@Target(ElementType.FIELD)      // 只能用在属性上
@Target(ElementType.TYPE)       // 只能用在类上

// @Retention：这个注解保留到什么时候
@Retention(RetentionPolicy.SOURCE)   // 只在源码中有效
@Retention(RetentionPolicy.CLASS)    // 编译时有效
@Retention(RetentionPolicy.RUNTIME)  // 运行时也有效（框架用的这种）
```
