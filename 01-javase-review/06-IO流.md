# 03 - IO流（⭐⭐⭐ 面试常考，开发常用）

## 一、IO流分类

```
按流向分：
  输入流（读数据）：InputStream / Reader
  输出流（写数据）：OutputStream / Writer

按类型分：
  字节流（处理所有文件）：InputStream / OutputStream
  字符流（处理文本文件）：Reader / Writer
```

## 二、核心体系

```java
// 字节流（读图片、视频、任何文件）
InputStream  →  FileInputStream、BufferedInputStream
OutputStream →  FileOutputStream、BufferedOutputStream

// 字符流（读文本文件，如 txt、java）
Reader  →  FileReader、BufferedReader
Writer  →  FileWriter、BufferedWriter
```

## 三、FileInputStream 读文件

```java
// 用 try-with-resources 自动关闭流
try (FileInputStream fis = new FileInputStream("test.txt")) {
    int data;
    // read() 一次读一个字节，返回 -1 表示读完了
    while ((data = fis.read()) != -1) {
        System.out.print((char) data);  // 转成字符打印
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

## 四、BufferedInputStream 缓冲流（效率更高）

```java
// 缓冲流：内部有个缓冲区（默认8KB），减少磁盘读写次数
try (BufferedInputStream bis = new BufferedInputStream(
        new FileInputStream("test.txt"))) {
    byte[] buffer = new byte[1024];  // 一次读1KB
    int len;
    while ((len = bis.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, len));
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

## 五、FileWriter 写文件

```java
try (FileWriter fw = new FileWriter("output.txt")) {
    fw.write("Hello, World!");    // 写入字符串
    fw.write("\n");                // 换行
    fw.write("第二行内容");
    // 自动关闭流，数据会写进去
} catch (IOException e) {
    e.printStackTrace();
}
```

## 六、BufferedReader 读文本（最常用！）

```java
// BufferedReader.readLine() 一次读一行，开发中最常用的读法
try (BufferedReader br = new BufferedReader(
        new FileReader("test.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {  // readLine 返回 null 表示读完
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```
