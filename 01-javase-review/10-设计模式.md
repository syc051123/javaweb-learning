# 07 - 设计模式（⭐⭐ 面试常考，框架源码常见）

## 一、单例模式（一个类只有一个对象）

### 饿汉式（线程安全，上来就创建）

```java
public class Singleton {
    // 类加载时就创建好，不会出现线程安全问题
    private static Singleton instance = new Singleton();
    
    // 构造方法私有化，不让外部 new
    private Singleton() {}
    
    // 全局访问点
    public static Singleton getInstance() {
        return instance;  // 直接返回已创建好的对象
    }
}
```

### 懒汉式（需要时才创建）

```java
public class Singleton {
    private static Singleton instance;
    
    private Singleton() {}
    
    // synchronized 保证线程安全
    public static synchronized Singleton getInstance() {
        if (instance == null) {          // 第一次调用才创建
            instance = new Singleton();
        }
        return instance;
    }
}
```

## 二、工厂模式（把创建对象的逻辑封装起来）

```java
// 不用工厂：到处 new，耦合度高
ChineseFood food1 = new ChineseFood();   // 改类名要改所有地方
WesternFood food2 = new WesternFood();

// 用工厂：创建对象的逻辑集中管理
public class FoodFactory {
    public static Food createFood(String type) {
        switch (type) {
            case "chinese":
                return new ChineseFood();  // 只在这里 new
            case "western":
                return new WesternFood();
            default:
                throw new IllegalArgumentException("未知类型：" + type);
        }
    }
}

// 调用者只需要传一个字符串
Food food = FoodFactory.createFood("chinese");
// 如果要改类名，只改 FoodFactory 一处就行
```

## 三、代理模式（Spring AOP 的底层原理）

```java
// 代理 = 找一个"中间人"帮你做事
// 比如：你要租房，中介（代理）帮你找房、签合同、办手续

// 房东要出租房子
public interface Rent {
    void rent();
}

// 真正的房东
public class Host implements Rent {
    @Override
    public void rent() {
        System.out.println("房东出租了房子");
    }
}

// 中介（代理）
public class Proxy implements Rent {
    private Host host;  // 代理持有真实对象的引用
    
    public Proxy(Host host) {
        this.host = host;
    }
    
    @Override
    public void rent() {
        System.out.println("中介带你看房");      // 额外功能
        host.rent();                             // 调用真实方法
        System.out.println("中介帮你办手续");     // 额外功能
    }
}

// 使用
public class Client {
    public static void main(String[] args) {
        Host host = new Host();          // 真正的房东
        Proxy proxy = new Proxy(host);   // 找中介
        proxy.rent();                    // 中介帮你搞定一切
        // 输出：
        // 中介带你看房
        // 房东出租了房子
        // 中介帮你办手续
    }
}
```
