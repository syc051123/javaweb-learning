# 04 - 反射（⭐⭐ Spring/MyBatis 框架底层原理）

## 一、什么是反射？

```java
// 反射：在运行时"看穿"一个类的所有信息
// 正常：用类创建对象 → Person p = new Person();
// 反射：拿到类的"设计图" → 想怎么玩就怎么玩

// 反射能干啥？
// 1. 运行时知道一个类有哪些方法、属性
// 2. 运行时调用私有方法、修改私有属性
// 3. 框架都是基于反射实现的（Spring、MyBatis）
```

## 二、获取 Class 对象的3种方式

```java
// 方式1：类名.class（最常用）
Class<?> clazz1 = String.class;

// 方式2：对象.getClass()
String s = "hello";
Class<?> clazz2 = s.getClass();

// 方式3：Class.forName()（最灵活，传字符串就行）
Class<?> clazz3 = Class.forName("java.lang.String");

// 三种方式拿到的是同一个 Class 对象
System.out.println(clazz1 == clazz2);  // true
System.out.println(clazz1 == clazz3);  // true
```

## 三、反射获取构造方法

```java
public class Person {
    private String name;
    public Person() {}
    public Person(String name) { this.name = name; }
}

// 获取所有构造方法
Constructor<?>[] constructors = Person.class.getConstructors();

// 获取指定构造方法，创建对象
Constructor<Person> constructor = Person.class.getConstructor(String.class);
Person p = constructor.newInstance("张三");  // 等价于 new Person("张三")
```

## 四、反射获取方法并调用

```java
// 获取所有公共方法
Method[] methods = Person.class.getMethods();

// 获取指定方法并调用
Method method = Person.class.getMethod("setName", String.class);
Person p = new Person();
method.invoke(p, "李四");  // 等价于 p.setName("李四")
```

## 五、反射访问私有属性（暴力反射）

```java
public class Person {
    private String name = "默认名";  // 私有属性
}

// 获取私有属性
Field field = Person.class.getDeclaredField("name");
field.setAccessible(true);  // 暴力破解！设置可访问

Person p = new Person();
String value = (String) field.get(p);    // 获取私有属性的值
System.out.println(value);               // 输出：默认名

field.set(p, "王五");                     // 修改私有属性的值
System.out.println(field.get(p));         // 输出：王五
```
