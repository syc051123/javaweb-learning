# 01 - 异常处理（⭐⭐⭐ 面试必考，开发必用）

## 一、异常体系

```
Throwable（所有异常的老祖宗）
├── Error（严重错误，程序处理不了）
│   ├── OutOfMemoryError（内存溢出）
│   └── StackOverflowError（栈溢出）
│
└── Exception（程序可以处理的异常）
    ├── RuntimeException（运行时异常，不检查也能编译通过）
    │   ├── NullPointerException（空指针）
    │   ├── ArrayIndexOutOfBoundsException（数组越界）
    │   ├── ArithmeticException（算术异常，如除0）
    │   └── ClassCastException（类型转换异常）
    │
    └── 非运行时异常（必须处理，否则编译报错）
        ├── IOException（IO异常）
        ├── SQLException（数据库异常）
        └── FileNotFoundException（文件没找到）
```

## 二、异常处理的3种方式

### 方式1：try-catch-finally（自己处理）

```java
try {
    // 尝试执行可能出错的代码
    int result = 10 / 0;  // 这里会抛出 ArithmeticException
} catch (ArithmeticException e) {
    // 捕获特定的异常
    System.out.println("除数不能为0：" + e.getMessage());
} finally {
    // 不管有没有异常，都会执行（用来释放资源）
    System.out.println("finally 一定会执行");
}
```

### 方式2：throws（抛出给调用者处理）

```java
// 这个方法不处理异常，甩锅给调用者
public void readFile(String path) throws FileNotFoundException {
    FileInputStream fis = new FileInputStream(path);  // 可能找不到文件
    // 调用这个方法的人必须处理这个异常
}
```

### 方式3：throw（手动抛出异常）

```java
public void setAge(int age) {
    if (age < 0 || age > 150) {
        // 手动抛出一个异常
        throw new IllegalArgumentException("年龄不合法：" + age);
    }
    this.age = age;
}
```

## 三、try-with-resources（Java7 引入，自动释放资源）

```java
// 传统写法：麻烦，容易忘写 finally
FileInputStream fis = null;
try {
    fis = new FileInputStream("test.txt");
    // 读取文件
} catch (IOException e) {
    e.printStackTrace();
} finally {
    if (fis != null) {
        fis.close();  // 手动关闭
    }
}

// try-with-resources：自动关闭，不用写 finally
// 注意：资源类必须实现 AutoCloseable 接口
try (FileInputStream fis = new FileInputStream("test.txt")) {
    // 读取文件，用完了自动关闭 fis
} catch (IOException e) {
    e.printStackTrace();
}
// fis 在这里已经自动关闭了
```

## 四、自定义异常

```java
// 自定义一个异常类，继承 Exception（编译时异常）或 RuntimeException（运行时异常）
public class AgeException extends RuntimeException {
    
    // 构造方法：传入错误信息
    public AgeException(String message) {
        super(message);  // 调用父类的构造方法
    }
}

// 使用自定义异常
public void setAge(int age) {
    if (age < 0) {
        throw new AgeException("年龄不能为负数：" + age);
    }
    if (age > 150) {
        throw new AgeException("年龄不能超过150：" + age);
    }
    this.age = age;
}
```
